# Práctica 13 - Aplicación móvil con múltiples vistas

## Descripción
Sistema web móvil que simula una tienda de productos.

La aplicación cuenta con:
- Pantalla principal con listado de productos
- Pantalla de detalle
- Formulario adaptado a móvil
- Navegación clara
- Diseño responsive

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Visualización de productos
- Navegación entre pantallas
- Formulario de compra
- Adaptación a dispositivos móviles

## Cómo ejecutar
1. Descargar la carpeta del proyecto
2. Abrir index.html en el navegador
3. Probar en modo responsive o en celular
