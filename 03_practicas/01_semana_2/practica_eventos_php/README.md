# Sistema de Registro con Manejo de Eventos

## Descripción

Aplicación web desarrollada en PHP que permite registrar información básica de un usuario.

## Datos capturados

- Nombre
- Correo electrónico
- Edad

## Eventos implementados

1. Guardar información
2. Validar datos
3. Limpiar formulario

## Validaciones

- Campos obligatorios
- Formato válido de correo electrónico

## Tecnologías utilizadas

- PHP
- HTML
- Método POST
