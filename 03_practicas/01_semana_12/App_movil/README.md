Mejoras implementadas
1. Optimización móvil

Se agregaron media queries para adaptar correctamente la aplicación a dispositivos pequeños.

    .btn{
        width:100%;
    }
}

Se mejoraron los botones y espacios visuales para facilitar el uso en pantallas táctiles.

    padding:15px;
